Personal Encrypted Backup

Personal Encrypted Backup is a private, single-user desktop backup utility. It creates client-side encrypted backup snapshots and stores them in the user's own Google Drive account.

Private by design: backup contents are encrypted on the user's computer before upload. This information page does not provide access to any backup, repository, account, or recovery credential.

How Google Drive access is used

  • Upload new encrypted backup data.
  • Read encrypted backup data for integrity checks and restoration.
  • List and manage files created for the backup repository.

Data handling

The utility is operated locally by its sole user. It does not run a separate application server, sell Google user data, use it for advertising, or share it with third parties. Google Drive access is used only to perform backup, verification, maintenance, and restoration requested by the user.

Access control

Only the Google account that explicitly authorizes the utility can be used. Access can be revoked at any time from the Google Account security settings.
